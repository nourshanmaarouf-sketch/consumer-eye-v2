عين المستهلك - خطوات الرفع
1) ارفع كل الملفات (مع مجلد icons) إلى الاستضافة.
2) Firebase Console > Authentication > Sign-in method: فعّل Email/Password و Anonymous.
3) Firebase Console > Firestore > Rules: الصق محتوى firestore.rules ثم Publish.
4) تأكد من وجود مستند الأدمن: admins/{uid}.
5) ارفع الرمز قبل اختبار التطبيق على الجوال. إذا ظهرت نسخة قديمة، امسح بيانات الموقع مرة واحدة.
